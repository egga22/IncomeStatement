# GitHub Pages Build Output

This folder contains the built static files for GitHub Pages deployment.

## About

This is the production build of the Teensville Income Statement Generator web application, generated by Vite from the source files in the `webapp` directory.

## Deployment

To enable GitHub Pages for this repository:

1. Go to your repository Settings
2. Navigate to Pages in the left sidebar
3. Under "Build and deployment":
   - Source: Deploy from a branch
   - Branch: Select your main/master branch
   - Folder: Select `/docs`
4. Click Save

The site will be available at: `https://teensville.github.io/IncomeStatement/`

## Rebuilding

To rebuild the static files:

```bash
npm run build
```

This command will:
1. Install dependencies in the webapp folder
2. Run the Vite build process
3. Output the built files to this `docs` folder
